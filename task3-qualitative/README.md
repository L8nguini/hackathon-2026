# The Qualitative Vibe Check

### The bright idea

Numbers tell us about a game, but not necessarily what it means. That comes from adding context for which we can use the LLMs' broad knowledge. Qualitative reasoning is a classic AI approach that abstracts numerical values and changes into meaningful qualitative states, such as increasing, decreasing, stable, or approaching a critical threshold. *A $70 game with overwhelmingly negative reviews might be a catastrophic AAA disappointment; a decade-old indie game with a huge player base might be a generational cult classic; a highly rated game with very few reviews might be a hidden gem; and something went wrong when a 2D pixel platformer demands an RTX 4090.* Participants will build a system that identifies patterns in game data (combining numerical values, categories, and contextual knowledge) and turns them into entertaining insights.

### The goal

Explore whether combining qualitative reasoning with LLMs can produce more informative and nuanced insights rather than prompting an LLM to interpret raw numbers alone.

### Data to use

- Kaggle Steam Dataset 2025. Useful properties include prices, release dates, genres, review sentiment and counts, platform compatibility, system requirements, and playtime information from user reviews. Not all properties need to be used.
- Participants can combine properties, define their own qualitative categories and thresholds, and add contextual knowledge to generate interpretations. 

### Evaluation

If the Tinder app is ready, the outputs could be evaluated there.
